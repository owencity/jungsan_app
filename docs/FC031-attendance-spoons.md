# FC-031 참석 응답 자동 스푼

2026-11-01 CTO 결정: 총무 본인 제외 참석자당 +10스푼. 한 번 지급한 스푼은 제외 후에도 유지한다.
서버 PR53은 술자리·총무·참여자별 최초 참석 응답에 한 번만 지급한다. 응답 수정·단위 추가·재추가는 재지급하지 않는다.
한 차수 이상 SELF/HOST SOBER/DRANK 응답이 기준이고 빈 응답·모두 불참·AUTO 기본값은 제외한다.

앱은 인원수로 스푼을 계산하지 않고 GET /auth/me의 기존 spoonCount를 표시한다.
홈 진입 시 목록과 함께 내 정보를 갱신해 로그인 당시의 이전 숫자가 계속 남지 않게 한다.
총무 방의 응답 현황 새로고침은 기존 상세 조회로 명단·응답·총무 누적 값을 갱신한다. 실시간 푸시는 추가하지 않는다.
운영 앱에 수동 스푼 버튼은 없고, API 없는 가상 체험은 운영 보상 검증과 구분한다.
서버 적용 전에도 기존 spoonCount 필드로 동작한다. 변경 검증과 운영·TestFlight 적용은 PR에 구분해 기록한다.

검증: Android compileDebugKotlinAndroid/testDebugUnitTest 성공, 230개(실패·오류·건너뜀0).
서버에서 30을 반환하면 홈도 30으로 갱신하고, 술자리가 모두 만료되어 목록이 비어도 30을 유지하는 회귀 테스트를 추가했다.
앱 자체 계산·증가 요청은 추가하지 않았다. 실제 DB 적립 검증은 백엔드 PR53의 CI, 최신 iOS/운영 확인은 별도다.
