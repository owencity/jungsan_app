## 수정

안내 존재를 즉시 한 번만 조회하던 XCTest helper를 제한 시간 내 등장 대기로 변경했다.
앱과 SpringBoard에 노출되는 안내를 찾아 해당 Continue 버튼만 누르고 안내가 사라졌는지 확인한다.
공유 테스트도 이름을 입력하기 전에 같은 준비를 거친다.
안내가 나타나지 않는 기존 키보드는 대기 한도 후 원래 검증을 진행한다.
이름이 비어 있거나 일부만 들어간 경우 재입력해서 덮지 않는다. 전체 값 일치·오류 해제·
다음 화면 이동·겹침 검증을 그대로 유지하며 실패 시 실제 값과 기기 화면을 추가 기록한다.

제품 코드·의존성·이름 규칙은 바꾸지 않았다. 테스트를 제외하거나 실패를 성공 처리하지 않는다.
Windows에는 Xcode가 없어 Swift 컴파일 및 iPhone/iPad 실행 결과는 후속 GitHub CI로 확인한다.
