# FC-033 공개 데모의 샘플 정산표 저장

빌드16에서는 정산표가 서버 연결 총무에게만 보이고 공개 데모에서는 이미지 저장에 접근할 수 없다.
기존 디버그 샘플을 데모 홈의 `샘플 정산표 보기·저장`으로 연결한다. 이름 확인을 마치거나
참여자A/B 역할을 선택한 뒤 접근하며, 뒤로가기로 같은 데모 홈에 돌아간다.

고정된 가상 25명/25,000원 예시다. 편집 중인 데모 방의 결과로 오해하지 않게 안내하고,
PNG 제목에도 `체험용 정산표 · 실제 송금 없음`을 표시한다. 새 계산·API·계정·스푼 변경은 없다.
서버를 연결한 운영 모드에는 버튼과 경로를 등록하지 않는다. 기존 이미지/플랫폼 저장 코드를 재사용한다.

기존 이미지 XCTest는 개발용 실행 인자를 제거하고 로그인 화면 → 공개 데모 → 참여자A →
샘플 정산표 → 실제 이미지 저장 메뉴로 이동한다. iPhone/iPad CI에서 동일하게 검증한다.
OS 사진 보관함 저장 완료·카카오톡 전송·Apple 심사 통과를 이 검사로 주장하지 않는다.

FC-027 심사 접근 준비의 연장이다. PR5 위 별도 PR로 보존한다. 빌드16에 이 변경이 포함됐다고
안내하지 않으며, 검증/후속 업로드 결과는 PR에 기록한다.
