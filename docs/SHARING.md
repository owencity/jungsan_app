# 공유 · 즉시 복사 후 카카오톡 열기 선택 (2026-10-30)

CTO 결정: 시스템 공유창 대신 공유 버튼을 누르는 즉시 복사하고, 완료 안내와 카카오톡을 열지 묻는 선택을 보여준다.

1. 정산방의 상단 `링크 공유`, 하단 링크 공유·재공유, 정산 후 입금 요청 모두 기존 안내 문구와 링크를 복사한다. 입금 요청은 기존 금액·계좌 안내도 함께 유지한다.
2. 클립보드 쓰기가 성공하면 `복사되었습니다`와 `카카오톡 앱을 열까요?`를 표시한다. 복사 실패 시 실패 안내만 보여주고 열기를 묻지 않는다.
3. `카카오톡 열기`를 선택한 경우에만 앱을 연다. 사용자가 대화방을 선택하고 붙여넣어 전송한다. 카카오 로그인·계정 연결·SDK 공유·자동 발송 기능은 추가하지 않는다.
4. `나중에`, 바깥 터치·뒤로가기는 확인창만 닫는다. 카카오톡 미설치·열기 실패도 클립보드를 지우지 않으며 수동 붙여넣기 안내를 보여준다. 다른 앱이나 스토어로 자동 이동하지 않는다.
5. 데모는 운영에 존재하지 않는 가상 방 링크 대신 기존 공개 데모 안내 URL만 복사한다. 서버 API·공유 토큰·로그인 계약은 바꾸지 않는다.

Android는 카카오톡 패키지만 조회해 시작 화면을 연다. iOS는 `kakaotalk://launch` 실행의 완료 결과를 받는다. iOS 사전 설치 조회나 전체 설치 앱 조회 권한은 필요 없다. 앱 실행 성공은 메시지 전송 성공을 뜻하지 않으므로 전송 완료 문구를 표시하지 않는다.

## 검증

- 기존 공통 테스트의 초대 URL·안내 문구·입금 요청을 유지한다. 빌드·실행 결과는 PR에 기록한다.
- iOS 화면 테스트는 카카오톡이 없는 CI 시뮬레이터에서 복사된 데모 URL, 취소 후 클립보드 유지, 카카오톡 열기 실패 후 클립보드 유지를 검사한다.
- 실제 카카오톡이 설치된 iPhone·Android에서 앱 실행·대화방 수동 붙여넣기는 별도 확인이 필요하다. 테스트에서는 실제 대화방에 메시지를 보내지 않는다.
- 기존 TestFlight 0.1.0(9)는 이전 시스템 공유창 방식이다. 이 변경은 새 빌드의 설치·검증 후 제출한다. PR1과 학습용 diff는 보존한다.
