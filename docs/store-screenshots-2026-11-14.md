# 2026-11-14 스토어 스크린샷

앱 0.1.0 빌드 20의 화면으로 App Store 이미지를 만든다. 기존 촬영 모드의 참여자 앱 화면과 타임라인은 현재 총무 전용 운영 흐름과 달라, 새 `store-*` 촬영 경로를 추가했다.

- 기준 소스: `6c59e618f6ad11289f818fac7b7434d0faacf327`
- 기존 화면 컴포넌트와 계산·표 렌더링을 그대로 사용한다. 운영 화면의 배치와 문구는 바꾸지 않는다.
- Debug 촬영 모드에서만 가상 7명의 자료를 불러온다. 운영 API나 실제 계정은 사용하지 않는다.
- 응답 현황은 6/7명, 차수별 예상 인원은 6/6/5명이다. 확정표 예시는 7명 모두 응답한 별도 술자리다.
- 예시 결제 합계는 242,000원, 총무 수취액은 192,000원이다. 기존 미리보기·확정 코드를 사용하고 테스트에서 합계를 대조한다.
- `Store screenshots (iOS 6.9")`를 이 브랜치에서 실행하면 iPhone Pro Max로 정산표·차수 입력·응답 현황·정산 확정·내 술자리를 촬영한다.
- 생성 이미지의 이름·금액은 예시 자료다. 스토어용 설명에도 예시 자료임을 표시한다.

이 변경은 촬영 도구 준비이며 서버 배포나 TestFlight 업로드를 하지 않는다. 운영 반영이 필요하지 않으므로 PR을 자동 병합하지 않는다.
