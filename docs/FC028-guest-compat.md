# FC-028 총무 앱의 비회원 명단 호환과 정산표

기준: 앱 PR3 `da6a1fd06f40daba2d9944f108bc4860fafc33b3` 위 별도 브랜치. 기존 PR은 병합하지 않는다.

백엔드 PR50/51은 비회원 참여자를 기존 명단에 `userId:null`로 반환한다. 기존 non-null Long 역직렬화는
명단 전체 조회를 실패시키므로 서버·웹 공개 전에 앱 호환 버전이 필요하다.

SParticipant와 Participant의 userId를 nullable로 유지한다. 가짜 계정 ID나 이름 매칭으로 비회원을
회원에 연결하지 않는다. 명단·응답·송금은 participantId로 유지하고 회원 총무 권한은 변경하지 않는다.
로컬 데모 알림은 후보를 만든 뒤 회원 ID 없는 대상은 제외한다. 회원 차단 목록에도 null을 넣지 않는다.

검증: Android testDebugUnitTest 224개, 실패/오류/건너뜀 0. null이 포함된 실제 계약 모양 JSON의
역직렬화, 총무/응답/송금 유지, 동명이인 분리, 회원 알림 제외, 표 API 인증·권한 실패, 표시 금액 유지,
차수·조정·송금 페이지 누락 방지와 긴 금액 대응을 확인했다. 10명은 8+2행, 25명 전체 보기와 캡처의 모든 차수·조정·송금·요약 유지도 확인했다. iOS 빌드는 CI에서 별도 확인한다.
기존 Kotlin datetime·Gradle/Android 플러그인 경고는 이번 수정에서 숨기거나 버전을 바꾸지 않았다.

## 총무 앱의 정산표

추가 결정(2026-10-31): 화면은 세로형으로 유지하되 확정 금액의 저장 이미지는 전원을 가로 열로 넣은 전체 PNG로 별도 생성한다.
이미지 최상단에 서버 transfers의 받는 사람별 최종 보낼 금액을 강조한다. 송금이 없으면 ‘보낼 돈 없음’, 수취인이 여러 명이면 각각 표시한다. 전체 부담·이미 결제는 계산 근거로 구분하며 이 값들로 송금액을 재계산하지 않는다. 복수 수취인 요약이 차수 상세보다 먼저 나오는 테스트를 포함한다.
기존 Compose 그래픽과 플랫폼 저장 창을 사용하고 새로운 라이브러리는 추가하지 않는다. Android는 파일 저장 위치 선택,
iOS는 시스템 저장/공유 창을 사용하며 iPad 팝오버 위치를 지정한다. 창을 연 것을 저장 성공으로 표시하지 않는다.
예상 표는 확정 저장 버튼을 제공하지 않는다. 이미지 크기가 기기 한도를 넘으면 누락·잘라내기 대신 오류를 안내한다.

실제 서버 모드의 총무 정산방에 `정산표 보기 · 캡처` 버튼을 연결한다. 서버 GET
`/api/v1/gatherings/{gatheringId}/settlement-units/{unitId}/settlement/table`을 기존 회원 인증으로 조회한다.
비회원이나 다른 참여자에게 버튼을 표시하지 않으며 서버도 총무 권한을 검증한다. 데모 결과를 실제 정산표처럼 만들지 않는다.

서버의 정수 표시값만 사용한다. 참여자를 세로 행으로 두고 차수별 이름·참여·안주·술·차수 부담을 표시한다.
2026-10-31 CTO 결정: 음료는 기존처럼 안주에 포함해 함께 나누고 화면·저장 이미지에는 ‘안주’로만 표시한다. 별도 음료 선택이나 배분 변경은 하지 않는다.
전체 화면은 인원 제한 없이 이어지고, 캡처 화면만 차수별 8명 단위로 나눈다. 원 단위 조정 뒤 전체 부담·이미 결제 요약과 송금 대상/금액을 붙인다.
원 단위 조정과 송금 목록도 별도 페이지에 빠짐없이 표시한다. 각 장에 예상/확정, 조회 시각, 정산방 ID,
전체 페이지 수, 전체 결제 합계를 표시한다. 동명이인은 참여자 ID로 구분한다. 최종 부담과 이미 결제한 금액을
구분하며 계좌·토큰은 표에 넣지 않는다. 조회 실패 시 이전 값을 지워 오래된 표를 최신처럼 보여주지 않는다.

세로 화면의 수동 캡처 외에 확정된 전원 가로형 PNG 저장을 제공한다. 저장 위치와 공유 대상은 사용자가 고르며 카카오 메시지를 자동 전송하지 않는다.
접근성 글자 크기나 작은 높이에서는 스크롤이 생길 수 있으므로 전체 내용 확인 안내를 제공한다.
앱 실기기의 표 가독성, 새 TestFlight 업로드, 실제 HTTPS 웹 연결·배포 검증은 아직 남아 있다.
학습 상태 UNRECORDED. 고정 diff와 최종 테스트/CI 결과는 PR 설명에 남긴다.

## FC-029 총무 확인 후 확정 (2026-11-01)

목표 인원 도달·전원 응답·차수 수정으로 자동 확정하거나 초과 인원을 제외하지 않는다.
응답 명단은 전체를 표시하고 총무가 이름을 눌러 ‘정산 대상에서 제외’할 수 있다(총무·결제자 제외 금지 유지).
‘명단 확인 · 정산 확정’으로 서버 미리보기를 읽은 뒤 ‘정산 확정’을 눌러야 송금이 고정된다.
미리보기 이후 응답·명단이 바뀌면 기존 revision/hash 검사로 재확인을 요청한다.
안주에 음료 포함 규칙은 그대로다. 예상 표는 PNG 저장을 허용하지 않는다.
기존 자동 정산 테스트를 총무 확인 정책으로 갱신했고 Android 단위 테스트와 컴파일을 통과했다.
iOS CI·새 TestFlight 빌드와 백엔드 PR52의 운영 적용은 별도 검증한다. 기존 빌드13은 FC-029 이전 버전이다.
